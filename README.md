🍔 Food Delivery Web Application
📌 Overview
The Food Delivery Web Application is an online platform where users can browse food items, add them to the cart, and place orders easily. It helps customers order food online and allows admins to manage food items and orders efficiently.

🎯 Objective
Provide easy online food ordering

Reduce manual work

Manage orders digitally

🚀 Features
User Registration & Login

Browse Menu

Add to Cart

Place Order

Admin Dashboard

Manage Food Items & Orders

💻 Technologies Used
HTML, CSS, JavaScript

Java (Servlet/JSP) / PHP
